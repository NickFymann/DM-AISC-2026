# Состояние замечаний DM-AISC-2026 — 01.10.2026

[Английский ответ для рецензентов](reviewer_response_en.md) сопровождает обновлённые `main.tex` и `build/main.pdf`. Предыдущая рабочая версия сохранена в `history/pre_finalization_20261001/`.

| Пункт | Результат ревизии | Граница утверждений |
|---|---|---|
| 1. Воспроизводимость | Полный тракт, размеры выборок, частоты/полосы, G/gamma, eta, epsilon/tolerance/pruning, нормировка, seeds и метрика описаны; исходники и среда сохранены. | Синтетическая постановка; tanh не объявляется измеренной I–V-моделью. |
| 2. Выбор | 720 независимых fit/validation/test задач; выбор проверен по validation, затем замороженная модель оценивается на test. | Старые test-selected результаты — только диагностика. |
| 3. Screening | Три числа для 15 840 кандидатов; четыре tuned test-ветки и 9720 matched validation-контролей. При eta=.01 все 3240 пар совпадают. | Fixed-parameter validation и tuned test ablation различены. |
| 4. Baselines/ресурсы | Ridge/SBL/LASSO/OMP настроены на общих validation-данных; 18 отдельных serial-профилей времени, peak RSS и inference. | Границы сеток раскрыты; глобальная оптимальность настройки не доказана. Runtime — один репрезентативный refit, не среднее по десяти реализациям. |
| 5. Повторы/шум | 10 повторов в каждой из 72 ячеек; clean/20/35/50 дБ; mean/SD/paired CI, Jaccard по одинаковому M и частоты включения. | Пары Jaccard зависимы, CI для них не строится. Измеренные PIM — future work. |
| 6. Сходимость | Девять исторических траекторий, cap/init sensitivity; все 720 выбранных моделей сошлись, 536 кандидатов исключены с сохранением диагностики. | Полные новые траектории сохранены для 240 выбранных SBL-моделей. |
| 7. Индексы | В статье сопряжены c,d и c≤d; соответствие хранимому порядку (a,b,e,c,d) проверено прямым вычислением. | Численный код и данные не менялись. |
| 8. UQ/новизна | Убраны calibrated-UQ и общие claims превосходства; сопоставлены работы 2024/2025; вклад — контролируемое исследование screening. | Новый принцип SBL и практическое превосходство не заявляются. |

Решения по M=8 и диапазонам гиперпараметров зафиксированы в [final_revision_decisions.md](final_revision_decisions.md). Готовность редакции не означает принятия статьи или закрытия замечаний самим рецензентом.
